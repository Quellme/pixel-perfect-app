# Arelo — Billing, Legal & Trial Feedback

Large scope. Suggest splitting into 4 phases so we can ship and test each cleanly. Confirm the phasing (or reorder) and I'll start with Phase 1.

## Phase 1 — Stripe subscriptions + trial

**Stripe setup**
- Use Lovable's built-in Stripe Payments (`enable_stripe_payments`) — no API keys needed, test mode immediately.
- One product: **Arelo** at £7.99/mo, 7-day free trial built into the price.
- Family plan: same price, seat limit 5 (enforced in app, not Stripe).

**Schema additions**
- `subscriptions` table: `user_id`, `stripe_customer_id`, `stripe_subscription_id`, `status` (`trialing|active|past_due|canceled`), `trial_end`, `current_period_end`, `cancel_at`, `credit_weeks` (int, for referral rewards).
- `family_groups` + `family_members` (owner + up to 5 user_ids).
- Add to `profiles`: `ref_code` (unique, generated on signup via trigger), `referred_by` (text, nullable), `referral_converted` (bool default false), `terms_accepted_at` (timestamptz).

**Server functions / routes**
- `createCheckoutSession` (createServerFn) — creates customer with `metadata.user_id` + `metadata.referred_by`, returns checkout URL with 7-day trial.
- `createBillingPortalSession` — for managing subs.
- `/api/public/webhooks/stripe` (TanStack server route) — verifies signature with `STRIPE_WEBHOOK_SECRET`, handles:
  - `customer.subscription.created/updated` — upsert subscription row.
  - `customer.subscription.trial_will_end` — insert `agent_messages` row with gentle nudge ("Your free week wraps up in 2 days — no rush, just a heads-up").
  - `invoice.payment_failed` — soft in-app banner ("Card didn't go through. Whenever you're ready, you can update it in settings").
  - `customer.subscription.deleted` — mark `status=canceled`, set `data_deletion_at = now() + 30 days`, schedule cleanup.
  - `invoice.paid` (first paid invoice) — if `referred_by` set and `referral_converted=false`: mark converted, add 1 week credit to referrer via `subscription.update({ trial_end: ... })` or coupon.

**UI**
- `/pricing` public page.
- `/dashboard/billing` — current plan, trial countdown (soft framing), manage via portal button, family seats.
- Trial-end conversion screen at `/dashboard/upgrade`: warm copy, "Keep going" CTA + "Not yet, take me to feedback" secondary.
- Soft banners (not modals) for payment_failed / trial_will_end.

## Phase 3 — Trial feedback

**Schema**
- `trial_feedback`: `user_id`, `nps_score` (0–10), `what_worked` text, `what_didnt` text, `contact_name`, `contact_email`, `submitted_at`. RLS: own rows only.

**Flow**
- `/dashboard/feedback` route, also linked from settings.
- Shown automatically once on day 7 before upgrade screen.
- On submit: insert row + `createServerFn` POSTs to Make.com webhook (`MAKE_FEEDBACK_WEBHOOK_URL` secret).
- If `nps_score <= 6`: show warm message + button "Give me 3 more days" → extends Stripe trial via `subscription.update({ trial_end: now + 3d })`.
